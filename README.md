# Кедр — лендинг строительства домов под ключ

Одностраничный сайт строительной компании: каталог готовых проектов с фильтрами, смета по разделам работ, расчёт ежемесячного платежа по ипотеке и таблица траншей оплаты. Без фреймворков и внешних библиотек — HTML, CSS и vanilla JS.

**Демо:** https://georgy-itech.github.io/kedr-dom/

## Что внутри

- **Каталог из 12 проектов** — фильтры по площади, этажности, количеству спален и материалу стен, четыре режима сортировки, счётчик найденного с `aria-live` и осмысленное пустое состояние с кнопкой сброса.
- **Смета по разделам** — вместо одной цифры показывает стоимость фундамента, коробки, кровли, окон, отделки и инженерии отдельно. Разделы без выбранной опции из таблицы исчезают. Пересчитывает цену за м² и срок строительства.
- **Ипотечный расчёт** — аннуитетный платёж, сумма кредита и переплата. Сумма подставляется из сметы автоматически, краевые случаи (нулевой взнос, предельный срок) обработаны.
- **Транши оплаты** — шесть этапов с процентом и суммой платежа, рассчитанной от текущей сметы.
- **Связка блоков** — кнопка «Выбрать» в карточке каталога подставляет площадь и материал в смету, проект — в форму заявки, и прокручивает к расчёту.
- **Аккордеон вопросов**, галерея построенных объектов, форма заявки с валидацией без `alert()`, тост об успешной отправке.
- Светлая и тёмная темы с сохранением в `localStorage`, `prefers-reduced-motion`, скрытые проверкой контрасты не ниже 4.5:1 в обеих темах.

## Стек

Чистые HTML, CSS и JavaScript. Никаких сборщиков и зависимостей — сайт открывается двойным кликом по `index.html`. Шрифты лежат локально в `fonts/`, внешних запросов страница не делает вообще.

## Что проверено

Автоматическими прогонами на Playwright: работа фильтров и счётчика, совпадение суммы разделов с итогом, корректность аннуитета на контрольных значениях, сумма траншей = смете, состояния формы, отсутствие горизонтального скролла на 320/375/768/1280/1600 px, ноль ошибок консоли, контраст текста в обеих темах, равенство высот карточек в ряду.
